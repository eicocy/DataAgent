# 索引与约束设计

| 表 | 索引/约束 | 支持场景 |
|---|---|---|
| users | UNIQUE(username) | 登录、重复校验 |
| datasets | (user_id, created_at DESC) | 用户数据集分页 |
| datasets | (user_id, status) | ready/failed 筛选 |
| dataset_columns | UNIQUE(dataset_id,name) | Schema 查找 |
| analysis_sessions | (user_id, updated_at DESC) | 会话列表 |
| analysis_sessions | (dataset_id, updated_at DESC) | 数据集会话 |
| analysis_messages | (session_id, created_at, id) | 稳定消息顺序 |
| analysis_records | (user_id, created_at DESC) | 历史分页 |
| analysis_records | (session_id, created_at, id) | 会话执行记录 |
| analysis_records | (dataset_id, status, created_at DESC) | 数据集分析统计 |

外键保证关系完整性；Service 同时验证 user_id，外键不能代替授权。状态字段使用应用层 Enum + CHECK（在目标 MySQL 版本可靠时）双重限制。
