# 数据库总体设计

## 原则

- 一个用户拥有多个数据集；所有业务资源可追溯到 user_id。
- 一个数据集有多个字段和分析会话；一个会话有多轮消息和多次分析记录。
- JSON 用于结构不固定但需要审计的 Tool 参数、结果摘要和 ChartSpec，不替代核心关系字段。
- 时间统一保存 UTC 或明确时区的时间戳，接口使用 ISO 8601，前端按 Asia/Shanghai 显示。
- 金额和聚合数值避免 FLOAT，源数据计算由 Pandas/Decimal 或数据库 DECIMAL 语义处理。

## 表

`users`、`datasets`、`dataset_columns`、`analysis_sessions`、`analysis_messages`、`analysis_records` 六张核心表即可满足首期，不为单一状态或类型建立无意义字典表。
