# 数据表字段字典

## users

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK, AUTO_INCREMENT | 用户 ID |
| username | VARCHAR(64) | NOT NULL, UNIQUE | 登录名，规范化后唯一 |
| password_hash | VARCHAR(255) | NOT NULL | 密码哈希，不返回接口 |
| status | VARCHAR(20) | NOT NULL DEFAULT 'active' | active/disabled |
| created_at | DATETIME(3) | NOT NULL | 创建时间 |
| updated_at | DATETIME(3) | NOT NULL | 更新时间 |

## datasets

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | 数据集 ID |
| user_id | BIGINT UNSIGNED | FK users.id, NOT NULL | 所有者 |
| original_name | VARCHAR(255) | NOT NULL | 展示文件名 |
| stored_name | VARCHAR(255) | NOT NULL, UNIQUE | 服务端随机存储名 |
| file_type | VARCHAR(10) | NOT NULL | csv/xlsx |
| file_size | BIGINT UNSIGNED | NOT NULL | 字节数 |
| row_count | BIGINT UNSIGNED | NULL | ready 后可用 |
| column_count | INT UNSIGNED | NULL | ready 后可用 |
| status | VARCHAR(20) | NOT NULL | uploading/parsing/ready/failed |
| parse_error_code | VARCHAR(64) | NULL | 稳定错误码 |
| parse_error_message | VARCHAR(500) | NULL | 安全错误说明 |
| created_at | DATETIME(3) | NOT NULL | 上传时间 |
| updated_at | DATETIME(3) | NOT NULL | 状态更新时间 |

## dataset_columns

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | 字段 ID |
| dataset_id | BIGINT UNSIGNED | FK datasets.id, NOT NULL | 所属数据集 |
| ordinal_position | INT UNSIGNED | NOT NULL | 原始列序 |
| name | VARCHAR(128) | NOT NULL | 规范字段名 |
| original_name | VARCHAR(255) | NOT NULL | 原表头 |
| data_type | VARCHAR(30) | NOT NULL | string/integer/decimal/date/datetime/boolean |
| nullable | BOOLEAN | NOT NULL | 是否存在缺失 |
| missing_count | BIGINT UNSIGNED | NOT NULL DEFAULT 0 | 缺失数 |
| unique_count | BIGINT UNSIGNED | NULL | 唯一值数 |
| sample_values_json | JSON | NULL | 最多若干安全样例 |
| created_at | DATETIME(3) | NOT NULL | 创建时间 |

唯一约束：`(dataset_id, name)` 与 `(dataset_id, ordinal_position)`。

## analysis_sessions

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | 会话 ID |
| user_id | BIGINT UNSIGNED | FK users.id, NOT NULL | 所有者 |
| dataset_id | BIGINT UNSIGNED | FK datasets.id, NOT NULL | 当前数据集 |
| title | VARCHAR(200) | NOT NULL | 会话标题 |
| status | VARCHAR(20) | NOT NULL DEFAULT 'active' | active/closed |
| created_at | DATETIME(3) | NOT NULL | 创建时间 |
| updated_at | DATETIME(3) | NOT NULL | 最近活动 |

## analysis_messages

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | 消息 ID |
| session_id | BIGINT UNSIGNED | FK analysis_sessions.id, NOT NULL | 会话 |
| role | VARCHAR(20) | NOT NULL | user/assistant/system |
| content | MEDIUMTEXT | NOT NULL | 展示文本 |
| status | VARCHAR(20) | NOT NULL | complete/partial/failed；用户消息为 complete，助手消息记录分析状态 |
| created_at | DATETIME(3) | NOT NULL | 创建时间 |

## analysis_records

| 字段 | 类型 | 约束 | 说明 |
|---|---|---|---|
| id | BIGINT UNSIGNED | PK | 记录 ID |
| user_id | BIGINT UNSIGNED | FK users.id, NOT NULL | 所有者冗余便于安全查询 |
| dataset_id | BIGINT UNSIGNED | FK datasets.id, NOT NULL | 数据来源 |
| session_id | BIGINT UNSIGNED | FK analysis_sessions.id, NOT NULL | 会话 |
| user_message_id | BIGINT UNSIGNED | FK analysis_messages.id, NULL | 触发问题 |
| assistant_message_id | BIGINT UNSIGNED | FK analysis_messages.id, NULL | 最终消息 |
| question | TEXT | NOT NULL | 当时的问题快照 |
| intent_summary | VARCHAR(500) | NULL | 产品级意图说明 |
| primary_tool_name | VARCHAR(64) | NULL | 主要 Tool |
| tool_calls_json | JSON | NULL | ToolCall 数组 |
| tool_result_json | JSON | NULL | 裁剪结果与摘要 |
| chart_json | JSON | NULL | ChartSpec |
| final_answer | MEDIUMTEXT | NULL | 最终回答 |
| execution_time_ms | INT UNSIGNED | NULL | 总耗时 |
| status | VARCHAR(20) | NOT NULL | pending/succeeded/partial/failed；首期不保存 running 或 cancelled |
| error_code | VARCHAR(64) | NULL | 稳定错误码 |
| error_message | VARCHAR(500) | NULL | 安全错误说明 |
| created_at | DATETIME(3) | NOT NULL | 创建时间 |
| completed_at | DATETIME(3) | NULL | 完成时间 |

JSON 中不保存密码、Token、连接串、完整 Prompt、完整数据集或隐藏思维链。
