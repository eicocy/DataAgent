# 术语与标识符字典

| 中文术语 | 英文标识符 | 说明 |
|---|---|---|
| 用户 | User | 系统账号与数据所有者 |
| 数据集 | Dataset | 上传并解析后的 CSV/XLSX 资源 |
| 字段 | DatasetColumn | 数据集列的类型与质量元数据 |
| 分析会话 | AnalysisSession | 围绕一个数据集的多轮分析 |
| 分析消息 | AnalysisMessage | user/assistant/system 消息 |
| 分析记录 | AnalysisRecord | 一次可审计的 Agent/Tool 执行 |
| 工具调用 | ToolCall | Tool 名、参数、状态、结果与耗时 |
| 图表协议 | ChartSpec | 前端可安全转换为 ECharts option 的数据 |

## Tool 规范名

`get_dataset_info`、`preview_data`、`filter_data`、`aggregate_data`、`group_by_analysis`、`sort_data`、`sql_query`、`generate_chart`。

## 示例销售字段

`order_date`（订单日期）、`region`（地区）、`product`（产品）、`sales`（销售额）、`quantity`（数量）。

## 状态词

- Dataset：`uploading`、`parsing`、`ready`、`failed`。
- AnalysisRecord：`pending`、`succeeded`、`partial`、`failed`。首期不提供 `cancelled` 状态。
- ToolCall：`validating`、`running`、`succeeded`、`failed`。

接口使用 snake_case；Vue 组件使用 PascalCase；前端变量可在适配层转 camelCase，但 API DTO 保留原字段名。
