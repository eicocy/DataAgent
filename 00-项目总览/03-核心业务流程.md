# 核心业务流程

## 上传数据

用户选择文件 → 客户端初检 → 后端安全校验 → 保存文件 → Pandas 解析 → 推断字段 → 保存 Dataset 与 DatasetColumn → 返回详情。

## 智能分析

用户选择数据集并提问 → 加载 Schema → Agent 识别任务 → LLM 选择 Tool 与参数 → Pydantic 校验 → Tool 真实计算 → 生成 ChartSpec（可选）→ LLM 只基于 Tool Result 总结 → 保存消息和记录 → 前端展示证据链。

## 历史回看

用户进入历史列表 → 按数据集、状态或时间分页查询 → 打开详情 → 查看原问题、Tool 参数、结果、图表和最终回答 → 可将原问题带回工作台再次分析。

## 失败原则

- 文件失败：保留原因，允许重选或重试。
- Tool 失败：保留用户问题与已完成步骤，不生成成功总结。
- 模型总结失败：仍可展示 Tool 结果，并标注总结不可用。
- 权限失败：不泄露资源内容，返回清晰 403 反馈。
