# 项目开发设计总览

## 定位

DataLens Agent 是面向非技术用户的智能数据分析助手。用户上传 Excel/CSV 后，通过自然语言提出问题；系统由大模型选择结构化 Tool，再由 Pandas 或受控 SQL 完成真实计算，最后由大模型基于 Tool Result 生成总结。

## 设计目标

1. 降低 Python、SQL 和复杂 Excel 操作门槛。
2. 让分析过程可解释、可追溯，而非只返回聊天答案。
3. 保证数值来自真实计算，模型不猜测结果。
4. 控制首期复杂度，使本科生能独立完成并在面试中讲清楚。

## 五个核心板块

- 产品原型：PRD、信息架构、交互规则和 HTML 高保真原型。
- 前端运行环境：Vue 3 工程与组件设计（仅文档）。
- 后端初始工程：FastAPI、Agent、Tool 和安全设计（仅文档）。
- 数据库：实体、字段、关系、索引与生命周期。
- 项目接口：REST API、错误码与跨层数据协议。

## 首期边界

采用单体前后端分离，不引入微服务、Redis、Kafka、Kubernetes 或 LangGraph。首期只支持 CSV/XLSX、常见筛选聚合、受控查询和基础图表。复杂统计建模、实时协作、定时报表和外部数据源不在范围。
