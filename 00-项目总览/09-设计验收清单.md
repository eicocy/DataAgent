# 设计验收清单

## 文档范围

- [x] PRD、信息架构、交互、前端、后端、数据库、API、Agent、Tool、SQL 安全、数据流和目录设计均存在。
- [x] 页面、API、数据表、前端组件之间存在映射。
- [x] 术语、URL、Tool 名和示例字段跨文档一致。
- [x] 文档没有把静态原型描述成已完成的真实产品。

## HTML 原型

- [x] `产品原型/index.html` 可通过本地文件打开。
- [x] 全部页面链接、CSS 和 JavaScript 相对路径有效。
- [x] 原型不依赖外部 CDN、不发起网络请求。
- [x] 登录、Dashboard、数据集、工作台、图表、会话、历史和状态页可浏览。
- [x] 工作台展示问题、Agent 阶段、Tool、参数、结果、图表和总结。
- [x] 原型明确标识模拟数据。

## 体验与安全

- [x] 核心页面有 loading、empty、success、error 和 permission 状态设计。
- [x] 无浏览器 alert/confirm/prompt，无伪造 Undo 或伪造计算结果。
- [x] 表单有标签，密码有显示按钮，搜索有清除按钮，Dialog 使用明确动词。
- [x] 表格和工作台在窄窗口可访问，图表提供数据表替代。
- [x] Tool 失败不显示成功总结；SQL 设计只允许受控 SELECT。

## 当前未实现

Vue/FastAPI 工程、依赖安装、数据库、真实登录、上传、Agent、Tool、图表计算、持久化、测试和部署均不属于本次交付。
