# 开发阶段规划

| 阶段 | 目标 | 可验收结果 |
|---|---|---|
| 1. 基础骨架 | 前后端分层、认证、统一响应 | 登录后进入空 Dashboard |
| 2. 数据集 | 上传、解析、预览、字段 | CSV/XLSX 可安全进入 ready/failed |
| 3. 分析核心 | Agent、Tool、记录 | 筛选与聚合返回真实 Tool Result |
| 4. 图表与历史 | ChartSpec、会话、详情 | 可回看完整执行证据链 |
| 5. 联调与展示 | 状态、错误、安全、体验 | 典型销售数据演示闭环 |

每一阶段只引入当前目标需要的能力。模型接入前可先用固定 Tool 选择打通真实数据链路，降低并行调试复杂度。
