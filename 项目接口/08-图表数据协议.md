# 图表数据协议

## ChartSpec

```json
{
  "version": "1.0",
  "type": "bar",
  "title": "各地区销售额",
  "subtitle": "销售额合计，单位：元",
  "dimension": {"field":"region","label":"地区","type":"category"},
  "metrics": [{"field":"sales_sum","label":"销售额合计","aggregation":"sum","unit":"元"}],
  "series": [{"name":"销售额合计","data":[{"name":"华东","value":"3286400.00"}]}],
  "source_tool_call_id": "tc_01",
  "notes": []
}
```

## 约束

- type 首期只允许 bar/line/pie。
- data 数值来自 Tool Result，金额可用十进制字符串，适配器负责安全转换显示。
- 不允许 formatter 函数、HTML、JavaScript、任意颜色表达式或远程资源。
- line 通常要求时间/有序维度；pie 只允许单指标和有限分类。
- 前端必须提供数据表替代、标题、单位和来源说明。
