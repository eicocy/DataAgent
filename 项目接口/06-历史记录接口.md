# 历史记录接口

## GET /api/v1/history

- Query：`q?`、`dataset_id?`、`tool_name?`、`status?`、`date_from?`、`date_to?`、`page`、`page_size`。
- Response：分页记录摘要：id、question、dataset、primary_tool_name、status、execution_time_ms、created_at。

## GET /api/v1/history/{id}

- Response：记录 ID、问题、数据集、intent_summary、tool_calls、tool_result、chart、final_answer、错误、耗时与时间。
- 大结果只返回保存的有限预览；如需完整数据，应由独立受控结果分页接口扩展，不把无限 JSON 塞入详情。
- 错误：`HISTORY_NOT_FOUND`、`HISTORY_FORBIDDEN`。

“再次分析”不是复制旧结果：前端读取详情后创建/选择会话，并把 dataset_id 与原问题提交到 chat。
