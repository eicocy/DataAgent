# 智能分析接口

## POST /api/v1/analysis/chat

### 作用

在指定会话和数据集上执行一次自然语言分析，返回 Agent 执行证据、真实 Tool Result、可选 ChartSpec 和总结。

### Request

```json
{
  "session_id": 2409,
  "dataset_id": 101,
  "question": "统计不同地区销售额并生成柱状图。",
  "request_id": "client_01"
}
```

规则：question 去首尾空白后 1–2000 字；session 与 dataset 必须属于当前用户且互相关联；request_id 用于客户端防重和追踪，不作为授权依据。

### 部分成功

Tool 成功但总结失败时 HTTP 200，status=`partial`，answer=null，保留 tool_result/chart，并提供 `summary_error`。这样前端能诚实展示真实结果而不伪造总结。

### 错误

- 400 `ANALYSIS_QUESTION_EMPTY`。
- 403 `ANALYSIS_DATASET_FORBIDDEN`。
- 409 `ANALYSIS_SESSION_DATASET_MISMATCH`。
- 422 `TOOL_VALIDATION_FAILED`。
- 503 `MODEL_UNAVAILABLE`。
- 500 `TOOL_EXECUTION_FAILED`。

错误 data 可含 `record_id`、`failed_step`、`retryable` 和安全的 `completed_tool_calls`，便于保留过程。
