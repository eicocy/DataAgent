# 统一响应与错误码

| HTTP | code | 含义 | 前端处理 |
|---|---|---|---|
| 400 | VALIDATION_ERROR | 请求格式错误 | 字段/表单错误 |
| 401 | AUTH_REQUIRED | 未登录或过期 | 重认证并返回任务 |
| 403 | RESOURCE_FORBIDDEN | 无资源权限 | 403 页面/禁用解释 |
| 404 | RESOURCE_NOT_FOUND | 资源不存在 | 404/列表刷新 |
| 409 | RESOURCE_CONFLICT | 状态冲突 | 保留输入并刷新 |
| 413 | DATASET_FILE_TOO_LARGE | 文件过大 | 上传区错误 |
| 422 | TOOL_VALIDATION_FAILED | Tool 参数无效 | Evidence Rail 失败节点 |
| 429 | RATE_LIMITED | 频率限制 | 告知重试时间 |
| 500 | TOOL_EXECUTION_FAILED | 真实计算失败 | 保留问题、重试 |
| 503 | MODEL_UNAVAILABLE | 模型不可用 | Tool 未执行则不显示结果 |
| 504 | SQL_TIMEOUT | 只读查询超时 | 修改问题/重试 |

错误 message 是面向用户的安全中文；开发排查依赖 request_id 和服务端结构化日志。
