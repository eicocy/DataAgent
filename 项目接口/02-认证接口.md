# 认证接口

## POST /api/v1/auth/register

- 作用：创建普通用户。
- Request：`{username, password}`；username 4–64 字符，password 至少 8 位。
- Response 201：`{id, username, status, created_at}`，不返回 password_hash。
- 错误：`AUTH_USERNAME_EXISTS`、`VALIDATION_ERROR`、`RATE_LIMITED`。

## POST /api/v1/auth/login

- Request：`{username, password}`。
- Response 200：`{user:{id,username,status}, expires_at}`；认证载体按最终安全方案返回或写 Cookie。
- 错误：统一 `AUTH_INVALID_CREDENTIALS`，不泄露用户名是否存在；禁用账号返回 `AUTH_ACCOUNT_DISABLED`。

## GET /api/v1/auth/me

- Response 200：`{id,username,status,created_at}`。
- 错误：未认证 `AUTH_REQUIRED`（401）。
