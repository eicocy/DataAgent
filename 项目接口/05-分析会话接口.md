# 分析会话接口

## POST /api/v1/analysis/sessions

- Request：`{dataset_id,title?}`。
- Response 201：`{id,dataset_id,title,status,created_at,updated_at}`。
- 错误：dataset 非 ready、无权限或不存在。

## GET /api/v1/analysis/sessions

- Query：`q?`、`dataset_id?`、`page`、`page_size`、`sort=updated_at:desc`。
- Response：分页会话摘要，含 message_count 和 last_question。

## GET /api/v1/analysis/sessions/{id}

- Query：消息可采用 `message_cursor`、`message_limit<=100`。
- Response：会话、数据集摘要、消息和下一游标。

## DELETE /api/v1/analysis/sessions/{id}

- 首期不可恢复，删除会话、消息和记录，不删除数据集。
- Response：`{deleted_id,deleted_at}`。
- 错误：正在执行返回 409 `SESSION_BUSY`；无权限 403。
