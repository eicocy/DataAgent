# 模块职责与依赖

| 层 | 职责 | 可依赖 | 禁止 |
|---|---|---|---|
| API | 认证、HTTP 参数、响应映射 | schema/service | Pandas、SQLAlchemy model |
| Service | 用例、事务、权限、编排 | repository/agent | HTTP 对象 |
| Repository | CRUD 与查询优化 | database/model | Agent、Pandas |
| Agent | 模型对话、Tool 选择与循环 | model/tool schema | HTTP、任意文件路径 |
| Tool | 结构化验证、真实计算 | data engine/safe SQL | 任意代码、写数据库 |
| Data | 文件句柄、DataFrame 生命周期 | filesystem | 用户响应 |

数据集文件只能通过 `DatasetHandle`（包含 dataset_id、owner_id、受控路径、Schema）取得，Agent 不接收磁盘路径。
