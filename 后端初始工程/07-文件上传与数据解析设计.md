# 文件上传与数据解析设计

## 限制

首期单文件 CSV/XLSX，默认上限 20 MB；实际值由配置统一控制。校验扩展名、MIME、文件签名、大小、空文件和压缩膨胀风险。文件名仅用于显示，磁盘名使用服务端随机 ID。

## 流程

`received → validating → stored → parsing → profiling → ready|failed`。XLSX 多工作表首期选择第一个非空表并在结果中说明；有歧义时要求用户选择，不擅自合并。

## 解析

CSV 尝试 UTF-8/UTF-8-SIG，再给出编码错误；采样推断类型后以全列校验。字段名去首尾空格并保留原名映射，重复字段生成明确失败或要求确认。解析失败删除未绑定临时文件。

## 安全

不执行宏、公式或外部链接；Excel 公式默认读取缓存值并标注。预览转义内容，防止 CSV 注入影响后续导出。原始内容不进入 Prompt。
