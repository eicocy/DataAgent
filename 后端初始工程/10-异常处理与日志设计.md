# 异常处理与日志设计

## 异常层次

`ValidationError`、`AuthenticationError`、`PermissionDenied`、`ResourceNotFound`、`DatasetParseError`、`ToolValidationError`、`ToolExecutionError`、`ModelUnavailableError`、`QueryRejectedError`、`ConflictError`。

API 全局异常处理器把领域错误映射为 HTTP + 业务错误码。未知异常返回通用消息与 request_id，详细堆栈仅写服务端安全日志。

## 结构化日志

字段：timestamp、level、request_id、user_id、route、dataset_id、session_id、record_id、tool_name、status、duration_ms、error_code。禁止记录密码、认证 Token、DeepSeek 密钥、完整 Prompt、完整原始数据和 SQL 中的敏感字面量。

## 可观测性

首期统计请求量、错误率、P95、解析耗时、Tool 成功率、模型失败率和 SQL 拒绝数。无需引入复杂平台，可先用结构化文件/控制台日志与简单指标。
