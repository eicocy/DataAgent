# 后端目录结构

```text
backend/app/
├─ main.py
├─ api/v1/              # auth、datasets、analysis、sessions、history
├─ core/                # settings、security、errors、logging
├─ database/            # session、base、migration glue
├─ models/              # SQLAlchemy models
├─ schemas/             # Pydantic request/response/tool schemas
├─ repositories/        # user/dataset/session/record persistence
├─ services/            # use-case orchestration
├─ agent/               # prompt、executor、model adapter、result policy
├─ tools/               # registry + eight tools
├─ data/                # file loader、schema profiler、safe frame handle
└─ utils/               # time、ids、pagination；禁止业务逻辑堆积
```

正式工程还应有 `tests/` 与迁移目录，但当前设计阶段不创建。
