# 分析任务执行流程

1. API 验证 `session_id/dataset_id/question`。
2. Service 校验 session、dataset 均属于当前 user，且相互一致。
3. 写入用户消息与 pending record。
4. 加载 Dataset Schema，构造 AgentRequest。
5. Agent 请求模型生成 ToolCall。
6. Registry 根据 tool_name 找 Tool；Pydantic 校验参数。
7. Tool 获取受控 DatasetHandle，执行真实计算并记录耗时。
8. 可选调用 generate_chart。
9. 将有限 Tool Result 交给模型总结。
10. 在一个明确事务边界内更新消息、record 与状态。
11. 返回 AnalysisChatResponse。

首期 `POST /analysis/chat` 同步等待 Agent 完成，不提供实时执行流或服务端取消。模型不可用时明确失败；Tool 成功但总结失败时返回 HTTP 200、`status=partial`、真实 Tool Result 和 `answer=null`。
