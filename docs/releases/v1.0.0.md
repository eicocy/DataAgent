# DataLens Agent v1.0.0

首个完整的本机数据分析 Agent 发行版。用户上传 CSV/XLSX 后，可以在同一会话中提问、选择或切换数据集、追问筛选条件与图表类型，并查看结果、计算步骤和证据。

## 主要能力

- FastAPI、Vue 3、MySQL 8 和 Compose 组成的单实例工作台；Alembic 迁移至 `0008_agent_orchestration`。
- 固定数据集版本的结构化意图路由、数据集消歧、`AnalysisPlan` 校验和受控 Tool Registry。执行器按依赖运行，限制步骤、调用、重试、重规划及总时限。
- 只读质量分析、统计和图表工具；图表追问复用同版本未过期的计算工件。数字结论由服务端从事实路径填入，并关联步骤、工具、工件和 Evidence。
- 持久后台任务、取消、Trace、SSE 事件重连和浏览器刷新恢复。模型调用只保存提供方、模型、Prompt 版本、Token、耗时和安全错误码。
- DeepSeek 主验收通过；提供 OpenAI 适配层与离线 Fake Provider。聊天入口不执行清洗写入。

## 验证

- 配置三条专用真实 MySQL 测试连接后，后端完整回归：**439 passed，0 skipped**，包括空库、带旧数据的 `0007→0008`、版本保留和只读账号权限。
- 前端：**29 项单测通过**、构建通过、模拟 API 浏览器测试通过。
- 真实 Vue、MySQL、DeepSeek 浏览器流程：**1 项端到端测试通过，15 项检查**，覆盖上传、两数据集、固定版本追问、图表复用、过期重算、取消、SSE 重连及跨用户隔离。受控样例与截图见 [验收记录](../phase3-acceptance.md)。

## 安装与边界

按 [README](../../README.md) 复制 `.env.example`，为每个数据库账号生成不同的随机密码和 `SECRET_KEY`，再配置真实 `DEEPSEEK_API_KEY`。示例配置中的 `replace_*` 值不能用于部署；实际凭据和用户数据不属于发行版文件。

本版保持单实例监督器。进程中断会明确终结任务，不跨重启续跑。OpenAI 真实调用尚待有效凭据单独验收。历史 MySQL 容器退出码 255 的精确原因缺少当时的错误日志；当前验收环境已恢复并设置 MySQL 自动重启。
