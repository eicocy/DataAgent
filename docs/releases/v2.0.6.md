# DataAgent V2.0.6

基于 V2.0.5，改善连续对话、超时控制和人工排查错误的体验。

- 普通聊天和分析规划共用有界上下文，兼容新旧筛选/分组参数；明确统计问题可进入通用分析。
- 模型单次默认上限 90 秒，同时受快速/标准/深度总预算约束；不对超时隐式重试，保留已完成成果。
- 新增持久化脱敏诊断、错误详情展开与复制，区分模型超时、任务总预算、工具失败、服务中断及计划校验。
- 保留固定版本与分析范围，中文执行步骤和历史错误恢复；浏览器请求超时提供重新连接确认状态。

升级前备份数据库，再在 backend 执行 `alembic upgrade head`，迁移头为 `0013_error_diagnostics`，重启后端以加载配置。`LLM_TIMEOUT_SECONDS` 默认 90，可配置覆盖；总分析预算保持 60/180/600 秒。沙箱仍默认关闭，单实例部署边界不变。

实际验证状态与限制见 [实施和验收](../v2.0.6-reliability.md)。不包含自动推送、标签或正式发布。

验证摘要：后端完整检查 905 通过、17 环境相关跳过；前端 85 单测与构建通过，7 条既有浏览器场景通过。实际 MySQL 升级及 PDF/DOCX/XLSX 文件检查完成。唯一一次真实电影分析在 17.86 秒结束，但因 `PLAN_INVALID / COLUMN_NOT_FOUND` 失败；原超时场景尚无成功验收结果。没有为获取成功结果追加模型调用。
