# DataLens Agent V2.0.2

发行日期：2026-10-04。对应 AI-Native Enterprise Data Analysis Workspace 升级计划的 **Phase 2**，基于 V2.0.1 增量交付，Phase 3—5 尚未实施。

## 本版内容

- 105 个版本化 AnalysisProfile、自动 Template Router 和最多三个 Profile 组合；模板表达分析策略，由 Planner 决定实际步骤。
- 保守的指标/维度识别、按数据版本隔离的 Session 语义映射，以及前端和自然语言字段修正。
- Plan 3.0 固定多个授权数据版本、模板和语义快照；公共步骤去重、DAG 校验、有限只读并行及 DEEP 有界探索。兼容旧请求和历史 Plan 1.0/2.0。
- 服务端节点、探索深度、模型调用、Token 和执行时间预算；复用已有计算、结果验证、事实引用、失败恢复与 SSE。
- Composer 开放实际可用模板、深度、模型和多输入选择；执行详情显示依赖、输入别名、探索来源和耗时，刷新保留请求选项。
- 修复去重误用筛选结果、必需标记丢失、重新规划探索来源、预期输出完成判定、字段编辑附件绑定，以及质量检查意图的只读工具策略一致性。
- 前端包与后端 API 版本为 2.0.2；新增迁移 `0010_analysis_profiles`，不修改已有迁移。

## 数据库升级

部署前备份数据库，然后在 `backend` 目录使用项目 Python 环境执行 `python -m alembic upgrade head`。迁移从 `0009_workspace_reports` 新增 `analysis_profiles` 和可空 `analysis_records.request_config_json`；旧数据版本和历史记录保留。Session 语义映射复用现有 JSON。

本地调试数据库已从 0009 升级至 0010；升级前保存了备份，原有 15 张业务表的数据校验一致，两条历史记录保留。备份只保存在本地忽略目录，不包含在发行内容中。

## 验证与限制

- Phase 2 实现验收：后端隔离 SQLite 完整回归 516 项通过、5 项跳过、16 个已有 Alembic 弃用警告。跳过项为未提供专用测试连接的 MySQL 测试。
- 额外隔离 MySQL 验证 1 项通过：0009→0010 迁移、旧记录保留及 Profile 幂等初始化，不使用业务数据库运行集成测试。
- 前端 56 项单测、生产构建和 3 个模拟 API 浏览器流程通过；检查桌面和 390px 窄屏截图。模拟浏览器流程不等同于真实模型端到端验收。
- 真实 DeepSeek 使用隔离数据库和两行模拟 CSV 验证 FAST / 数据质量 Profile：Plan 3.0、四项检查和事实总结成功，15.5 秒、3 次调用、11,009 Token。该样例不代表全部业务数据和模型输出均已验收。
- 本阶段多输入支持分别分析和对照，尚不支持跨表 Join。专业销售/财务口径、周期比较、贡献分解和预测属于 Phase 3；自动多格式报告、完整 Artifact 引用/长期留存属于 Phase 4；生成 Python 的独立沙箱属于 Phase 5。现有手动报告继续可用。
- 单实例部署和用户所有权隔离保持现状；并行仅面向受信任注册工具，不开放自由 Python。未进行正式部署或生产安全认证。
