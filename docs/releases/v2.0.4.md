# DataAgent V2.0.4

Phase 4 已由用户验收。本版完成 AI-Native Workspace 升级计划的 Artifact 与报告交付，基于已发行 Phase 3；Phase 5 Python 沙箱尚未包含。

## 主要变化

- ArtifactManager 统一配额、会话授权、就绪与过期状态；证据及最终交付长期保留，未引用的中间产物按策略清理。增量迁移 `0012_artifact_workspace`。
- 结构化成果引用固定数据版本、完整工具事实与血缘；图表追问和报告复用既有结果，禁止凭空补统计值。重新生成创建新工件。
- 会话恢复分析结果、报告与选中工件；Vue 提供 Artifact 面板和引用选择，修复报告记录遮蔽分析和即时编辑器空白。
- 提供自动、简版、详版、管理层、技术、数据质量和预测七种报告模板；PDF/DOCX 完善封面、目录、页码和证据附录。
- XLSX 保留原始数据及完整清洗数据，固定多输入来源，分块明细并防止公式注入；Python 导出可按授权输入重现计算，保留 Decimal 精度；SQL 仅导出经过验证的只读查询。
- 分析后的多格式报告在同一个监督任务及预算内交付，支持幂等、取消、部分失败和已成功文件保留。

- 小份模拟数据验证真实计算、Artifact、报告预览及认证下载，生成并打开 PDF、DOCX、XLSX。PDF 与 Word 各四页已查看；Word 使用本机 Word 转换后查看。
- Phase 4 浏览器冒烟 1 项通过，生产构建、UI strict 和 whitespace 检查通过。

## 升级及限制

部署前备份数据库、上传文件与 Artifact，再通过既有 Alembic 流程升级至 `0012_artifact_workspace`。旧文件缺失会明确显示过期；迁移不会伪造历史文件。

本版未新增真实模型调用，浏览器自动冒烟使用固定接口样例；真实计算、API 和导出另由隔离后端检查覆盖。没有执行压力或大规模兼容性测试、正式部署、业务库迁移。独立审查调用因账号用量限制失败，未取得审查结论。沙箱执行和 Phase 5 安全加固尚未实施。
