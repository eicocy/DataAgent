## 限制

质量分数不是行业标准，贡献不证明因果，残差范围未经校准。首次解析/旧投影可能浮点和八位小数近似，精确工具不能恢复已丢失精度。本版没有 OCR、多对多 Join、自动换汇、树模型/外部变量、Artifact 长期留存/@引用、自动多格式交付或 Python 沙箱。normalized-only 结果表不能恢复缺失的完整 typed 指标，界面明确展示这一限制。

既有手动报告 API 在真实监督任务中仍创建 READY 报告，固定来源版本、详情和六个文档章节可读取。任务完成响应提供的报告摘要可能没有完整 document，导致即时编辑器显示无章节；组件已有 document 章节回退，问题在于尚未取得完整详情，不能归因为缺少该回退。创建手动报告后，Workspace 以最近报告任务为证据时可能暂不展示前一分析的工具结果，原生历史详情仍可读取。两项历史可用性问题记录为 Phase 4 范围，本版不声称该工作台报告流程或所有导出格式完成真实浏览器验收。
