# DataLens Agent V2.0.1

发布日期：2026-10-03。对应新版 AI-Native Enterprise Data Analysis Workspace 升级计划的 **Phase 1**，基于 v2.0.0 增量交付，Phase 2—5 尚未实施。

## 本版内容

- 极简分析首页与统一输入框；延迟创建会话，文本输入、中文 IME 和拖拽/多文件上传。
- 逐文件上传队列、工作表选择、错误重试及会话附件绑定、刷新恢复和删除。
- 15 个方向、105 个模板的只读目录，明确显示可用、受限和规划中。模板填入可修改示例，未开放 Profile 执行和自动领域路由。
- 复用现有 Agent、ToolRegistry、数据版本、图表、报告和历史接口；补齐已有图表协议适配、PATCH 跨域及异步状态修复。
- 文件与发送按钮复用 Element Plus；历史详情按任务类型展示中文标题、状态、文件和时间。报告记录提供返回所属会话入口，隐藏空的分析工具区，结果内容仍来自服务器记录。
- 前端包及后端 API 版本为 2.0.1，数据库迁移头保持 `0009_workspace_reports`。

## 验证与限制

- 后端完整回归在临时 SQLite 与禁用真实模型的隔离配置下运行：482 passed、4 skipped、14 个现有 Alembic 弃用警告。跳过项为未配置专用测试连接的真实 MySQL 集成测试，未使用本地业务数据库运行这些测试。
- 前端：51 项单测、生产构建和 2 项模拟 API 浏览器流程通过；严格 UI 静态检查无发现。
- 真实本地页面：检查首页及已有报告记录、发送禁用/启用状态、桌面与 390px 窄屏布局。
- 本地 MySQL 连接、空库初始化、迁移至 0009 和 API 就绪检查通过；这不代替专用隔离数据库的权限和完整业务集成测试。
- 模型配置存在；本次版本收口未调用真实模型，也未验证 Docker 部署。
- Profile 路由、多数据集执行、深度预算、专业销售/财务/预测工具、Artifact 引用和长期留存、独立 Python 沙箱仍属于后续阶段。

启动方式见 [README](../../README.md)。本地环境配置、模型 Key、数据库凭据、上传文件和生成工件均不包含在 Git 发行版中。
