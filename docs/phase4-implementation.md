# DataAgent v2.0.0 Phase 4 实施与验收

> 状态：Phase 4 核心功能已实现，外部模型和真实服务浏览器验收尚未完成；本文不是正式发行声明。

## 已实现

- Vue 工作台提供最近会话侧栏、重命名、置顶、删除确认、数据集选择、对话和可调整的证据/工件面板；平板与手机使用覆盖式工件面板。
- 上传支持 CSV、TSV、JSON/JSONL、XLS、XLSX 工作表选择及 Parquet，并沿用行数、列数、文件大小和内存限制。
- 新增 0009 迁移及版本化报告存储；报告创建和导出通过现有后台监督队列运行，支持任务详情、事件流和取消。报告编辑创建不可变新版本。
- 支持 PDF、DOCX、XLSX、HTML、Markdown、CSV、JSON 导出；授权工件接口提供预览、Range 下载与所有者隔离。
- 新增 SVG、300 DPI PNG 和缩略图渲染；支持面积、瀑布、漏斗图，并复用已有图表数据。
- Python API 与前端包版本号设为 2.0.0。

## 验收结果

- 后端完整 pytest：通过；普通本地运行中的 4 个 MySQL 集成测试因未配置 TEST_MYSQL_* 而跳过。

- 前端 Vitest 4.1.11：**12 个文件、37 项测试通过**；Vite 生产构建通过。
