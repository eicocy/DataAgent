# V2.0.6 对话界面迭代

本轮沿用 Vue 3、Element Plus、Options API、字体和品牌色，将默认工作台调整为单栏对话。版本仍为 2.0.6；没有修改服务端接口、数据库、模型提示词、任务状态或中断协议。

## 已完成

- AppShell 提供独立对话布局：顶栏显示会话标题和文件入口，管理页面保留原布局。侧栏优先新对话、文件、最近会话，数据集、模板、历史、概览和全部会话放入“更多”，原路由继续可用。
- 空白页仅显示“想分析什么？”、输入框及概览数据、检查质量、生成图表三个建议。附件加号菜单提供上传、已有数据、成果引用和附件设置；多输入、字段含义确认及文档候选确认位于附件设置。上传进度、错误和附件标签仍可见。
- ChatMessage 展示无外框助手正文和浅灰用户气泡。正文最大宽度 760px，15px、行高 1.75。输入区留在底部，阅读区域独立滚动；用户向上阅读时，新结果不会拉回底部，提供“回到最新”。
- SafeMarkdown 使用精确版本 `markdown-it@15.0.3`，同步锁文件。关闭原始 HTML 和图片规则，保留默认安全链接检查；不改写模型原文及计算数值。
- AnalysisResult 新增 `presentation="chat"`，默认仍为 full，供历史、数据集及完整预览继续复用。按 expected_outputs、图表来源表排序并按来源去重；旧协议解析 source_tool_call_id，缺少关联时按保存工件编号或原 DTO 顺序降级。默认至多两张图、一张表、十行，其余通过“查看其余 N 项结果”展开。专业结果组件增加可选紧凑模式，单位、币种、缺失和方法限制保留可见。
- LazyChart 通过 IntersectionObserver 按视口挂载，展开预览时直接挂载，离开会话释放图表及观察器。原 ChartView 继续负责缩放、下载和资源释放。
- 每条回复使用自己的 record_id、artifact_id、固定版本及公开选项。旧消息的分页、放大、文件、报告和重新分析不会回退到最新结果。重新分析创建新的请求，保留原问题和输入版本；缺少原多输入附件时要求先恢复附件。
- 提交和刷新均不自动打开右侧。点击放大、完整数据或文件时打开原有可调宽度预览；手机全屏，背景对话 inert，支持键盘循环、Escape、关闭后焦点返回。
- 运行时一行真实状态加折叠步骤；失败原因由所属消息统一显示，步骤只提供状态与定位诊断入口。修复历史用户消息共享错误详情导致的重复错误。纯聊天不显示空结果和无内容的分析步骤。

## 文案删除与保留

删除的常驻文案：

| 原文案 | 处理 |
| --- | --- |
| 真实数据计算 · 可核对执行证据 | 删除对话页宣传标题 |
| 基于服务器端计算结果回答 | 删除聊天副标题 |
| 每个结论都有数据依据 | 删除侧栏常驻说明 |
| DATA ANALYSIS WORKSPACE | 删除空白页英文标语 |
| AGENT WORKSPACE | 删除品牌下方重复标语 |
| 本地工作区、Data workspace | 顶栏改为真实会话标题 |
| 智能分析、分析对话 | 删除同页重复标题 |
| Hey！今天想分析什么数据？及长介绍 | 改为“想分析什么？” |
| 可先聊天，分析前请选择数据集或上传文件 | 删除常驻输入区说明 |
| 图表、结果表和工具轨迹 | 不再常驻展示右侧功能介绍 |
| 工具原始名、完整参数、重复目标、来源 JSON | 移入按需展开详情 |

继续保留的业务提示：文件进度与失败原因、需要人工核对的文档候选、字段含义与单位确认、多输入版本说明、结果行数与分页、统计/预测限制、币种和单位、未记录信息的降级提示、具体失败原因与改善建议、已保留成果、中断确认、网络状态未知时重新连接、不可用能力提示。模型历史回答不做文案清理。

## 实际验证

- 前端全量 22 个文件、102 项单测通过；末次补充展示边界后，相关 22 项再次通过。包含安全 Markdown、来源选择与去重、十行限制、保留结果、单次诊断、懒加载、取消旧请求、跨轮分页/下载/报告、旧回复重新分析的固定版本，以及既有上传、输入法、中断、幂等恢复用例。
- 7 条既有 Playwright 场景通过，覆盖上传失败重试、聊天、刷新任务恢复、模板/深度/多输入、字段确认、清洗/合并、专业结果、旧记录降级、文件引用及手机布局。测试使用受控 API，无真实模型调用。
- 独立浏览器流程验证：旧记录 #4 的完整表从 `/analysis/runs/4/results/31` 读取首/次页，放大保持 #4/版本 11，文件只读取 #4 的工件，报告提交 `source_record_ids=[4]`。最新记录 #9 未替代旧记录。
- 模拟任务完成前后阅读位置均为 200px；回到最新后距底部 0px。输入区实际宽度 320/480/720px 时工具栏同一行、无重叠或横向溢出。390px 视口文档宽度 390px，完整预览 x=0、宽390、高786，Escape 后焦点回到“查看完整数据”。附件菜单和设置面板支持 Escape/焦点返回。
- 生产构建通过。既有 jsdom 模拟网络错误及 loading 指令桩警告未导致测试失败；模拟 SSE 断连的浏览器检查会出现预期 ERR_FAILED，再由原轮询恢复。
- 从新会话文件入口实际预览、下载既有工件 #4 PDF、#5 DOCX、#6 XLSX。三份下载与原保存文件逐字节一致；PDF 可读取 8 页，DOCX 可读取 19 段/5 表，XLSX 九个工作表可读取，Raw Data 为 3572 行（含表头）。三份文件均来自报告 #2 / 分析记录 #1 / 数据版本 #1 / 来源工件 #1、#2、#3。没有生成新报告或追加模型分析来完成文件验收。

本轮未重新验证真实模型电影分析的成功率、Safari/移动真机或原生 Office 打印排版；浏览器文件预览和文件结构读取不等于重新进行排版验收。原超时场景的验收边界仍见 [可靠性记录](v2.0.6-reliability.md)。本地配置和未跟踪资料保持原状。
