# Phase 5：稳定性、安全与部署准备

本阶段基于已发行 V2.0.4 / `8ab210d`，按 `UPGRADE_PLAN.md` Phase 5 交付 V2.0.5。数据库迁移头保持 `0012_artifact_workspace`，没有新增默认表、公开任意代码接口或宿主 Python 执行入口。用户本地配置、凭据和 `plan/` 不属于发行内容。

## 已实现

- 默认关闭的 Python 沙箱：应用、broker 和 runner 校验 AST 与固定协议；仅授权固定 DatasetVersion 快照进入容器。模型代码提案仅接收字段、类型、行数及绑定信息，不接收原始行。禁用状态保持原注册工具规划契约和 FAST 预算。
- 注册工具优先；两次受控规划仍缺少未注册能力且 broker 健康时才提出私有沙箱计划。已有工具、参数错误和写入能力不获得代码执行授权。计划绑定输入、配置及代码摘要，结果复用 AnalysisEngine、类型校验、执行证据、Artifact、事实绑定和报告。
- 独立 Docker broker 使用固定镜像及运行参数；执行容器非 root、只读、无网络、cap drop ALL、禁止提权，无宿主目录、Docker socket、模型 Key 或数据库连接。固定 1 CPU / 512 MiB / 无额外 swap / 64 PID / 最多 60 秒 / 64 MiB 输出。
- 输出仅接受受限 JSON 表格和最多四幅 PNG。拒绝路径穿越、链接、未知文件、非有限值及错误结构；PNG 解码后重新编码。可信镜像内的固定导出器读取 tmpfs，执行容器保持存活直到收集结束，再销毁。
- 取消、任务租约失效、超时、OOM、输出配额与 broker 重启可控；销毁失败保留句柄并重试，成功读取后 DELETE 立即释放结果，所有驻留输出合计限制 128 MiB。Docker exec 与退出状态之间的竞争等待最终容器状态，不把资源失败误报成格式错误。
- 沙箱凭据/代码不进入安全日志；Nginx SSE 关闭缓冲和缓存，保留认证与 Origin。可选 `compose.sandbox.yaml` 和 `docs/operations.md` 提供部署准备、升级与恢复流程。
- `deploy/backup.py` 对已有 SQL dump 和数据目录生成 SHA-256 manifest、复验与空目录恢复；拒绝危险路径、链接、重复条目、超额归档和校验不一致，不覆盖现有数据。
- 修复完整表格的报告事实读取：表格行与元数据统一参与事实绑定；修复 overview 的数据集行数被空结果表行数覆盖，新预览保留原始计算事实。

## 实际检查

开发中只跑受影响检查，模型采用固定 Provider。AST、协议、输出攻击、健康/租约、授权与取消、备份、私有 Agent 全链路各有针对性验证；既有强制 CI 保持。一次独立整分支审查没有 Critical，四项 Important 均经过复现与修复：高阶统计调用的动态分派、原始行进入模型提案、结果驻留内存、中文 JSON 线协议膨胀。相关组合检查 34 passed；后续报告事实绑定组合 8 passed，overview/取消/私有流程组合 4 passed，Docker 退出状态竞争检查 3 passed。未为文档新增重复实现逻辑的测试。

最终关键链路使用两行一列模拟 CSV，值为 1 和 3，在独立 SQLite 与文件目录执行一次真实 `deepseek-flash` 工作流。共 3 次模型调用、9,218 Token；overview、缺失检查、字段摘要完成，答案正确引用 2 行、1 列、0 缺失和 2 个唯一值。首轮报告交付发现表格事实读取缺陷；修复后直接复用保存结果完成交付，没有重跑模型分析。

PDF、DOCX、XLSX 各实际生成一个文件，通过认证预览和下载；XLSX 打开并核对 Raw Data 两行及来源。PDF 用 Poppler 查看四页，DOCX 用本机 Word 转为 PDF 后查看四页，中文、长表续页、页码和证据索引正常。标准 Word 渲染器此前环境超时，本次沿用可用的本机 Word 转换，不将其记作标准渲染器通过。

实际 Vue + 隔离后端浏览器检查已保存答案、成果恢复、PDF 内嵌预览、报告工作区、Excel 明细预览及浏览器下载，控制台无错误。SSE 完成事件回放、Last-Event-ID 重连无重复终态通过。小样例旧缓存的 overview 预览形成于修复之前，仍保留历史内容；真实 Artifact/答案/报告中的行数为 2，新增预览修复另由针对性检查验证，没有改写历史答案或计算事实。

真实隔离 MySQL 从 0009 升至 0012，旧 Plan/Session 保留、Profile 初始化仍为 105，迁移检查 1 passed。真实 mysqldump、归档校验、文件恢复和新隔离库 SQL 恢复通过，旧记录、迁移头和文件内容一致；仅清理本次创建的测试库，没有操作业务库。

Linux Docker 的资源隔离、表格/PNG、OOM、超时、输出配额、取消、租约过期、重启孤儿清理，以及 Nginx 配置由 GitHub Actions sandbox job 实测。发行前以最终提交的 backend/frontend/sandbox 三个 job 成功为准，详细结果见 [Actions](https://github.com/eicocy/DataAgent/actions/workflows/ci.yml)。普通 CI 的前后端测试及浏览器替身流程不调用付费模型。

## 边界与未验证范围

- 本机 Windows Docker Desktop 引擎未就绪；真实容器检查在 Linux CI 完成，不声称 Windows 本机沙箱验收通过。
- 真实模型验证普通注册工具链路；沙箱提案到私有执行/证据使用固定 Provider 验证，真实容器另由 Docker CI 验证。未额外进行付费模型与真实 broker 的组合验收。
- 未生产部署、业务库迁移、压力测试、大规模兼容性测试或安全认证。系统仍为单实例监督器，重启终结旧任务，不跨重启续跑计算。
- 沙箱限制语言和库操作，高阶统计只允许显式安全统计名或受限 lambda；不支持任意第三方代码、动态函数分派、外部文件/网络、任意模型库或写入任务。攻击 fixture 不等于对所有对抗性程序的证明。
- 备份校验不提供加密或来源认证；多库一致性需要按手册停写并配对备份。旧缓存预览不自动重写，旧文件缺失不补造。
