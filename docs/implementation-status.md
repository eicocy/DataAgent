## 可复核口径

销售样例 `sample-data/sales_growth_demo.csv` 的六个月末月为数据最大日期所在月；增长率=(末月-首月)/首月。A/B/C分别100%/50%/20%；首月非正或端点缺失的D/E排除；缺失月份不补零。完整结果用于下游计算，工件保留7天，历史保留有界快照和Trace；过期分页返回410。

首期必须单实例、单 Uvicorn worker。仅有会话背景，不允许用已过期历史预览作为计算来源；追问需要重新计算授权数据集。浮点计算适合探索分析，数值投影最多8位小数，质量警告明确该精度策略。
