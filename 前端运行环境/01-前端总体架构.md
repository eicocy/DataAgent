# 前端总体架构

## 技术边界

Vue 3 + Vite + Vue Router + Pinia + Axios + Element Plus + ECharts。新组件默认使用 Options API；如未来引入 `<script setup>`，只在明确的局部组件中使用，不混合迁移整个项目。

## 分层

```mermaid
flowchart TD
  View[Views 页面编排] --> Store[Pinia 业务状态]
  View --> Components[共享/领域组件]
  Store --> API[API modules]
  API --> Client[Axios client]
  Components --> Types[DTO / ViewModel]
  Store --> Types
  Client --> Backend[/api/v1]
```

- View 只编排路由数据、Store 与组件，不直接写 Axios。
- Store 拥有跨组件业务状态与异步动作。
- API module 一一对应后端资源，不保存 UI 状态。
- Components 分 shared、dataset、analysis、chart；共享行为不在页面重复。
- 类型区分 API DTO、领域模型和视图模型，转换集中在 mapper。

## 关键约束

- 图表只消费受控 ChartSpec。
- Tool 参数以只读方式展示，不由页面拼接执行。
- 搜索请求 300ms 防抖、IME 安全，并取消或忽略旧响应。
- token 不放 URL；敏感值不进入日志、Toast 或 localStorage。
