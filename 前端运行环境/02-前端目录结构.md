# 前端目录结构

```text
frontend/src/
├─ api/                 # auth/datasets/analysis/sessions/history
├─ assets/              # 全局样式与静态资源
├─ components/
│  ├─ shared/           # Button、Dialog、DataTable、EmptyState
│  ├─ dataset/          # 上传、预览、字段
│  ├─ analysis/         # 消息、EvidenceRail、ToolCallCard、结果
│  └─ chart/            # ChartPanel、ChartDataTable
├─ layouts/             # AuthLayout、AppLayout
├─ views/               # 路由页面
├─ router/              # routes、guards、title
├─ stores/              # auth、dataset、analysis、ui
├─ types/               # DTO、domain、chart、tool
├─ utils/               # format、error、request-id、chart-adapter
├─ constants/           # 路由名、状态、分页默认值
├─ App.vue
└─ main.js
```

文件按责任拆分，不创建通用 `helpers.js` 垃圾桶。只在至少两个消费者真实复用时提升为 shared。
