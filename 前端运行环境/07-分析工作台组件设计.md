# 分析工作台组件设计

```text
AnalysisView
├─ DatasetPanel
│  ├─ DatasetSelector
│  ├─ FieldList
│  └─ SuggestedQuestions
├─ ChatPanel
│  ├─ MessageList
│  ├─ EvidenceRail
│  │  └─ ToolCallCard
│  └─ MessageInput
└─ AnalysisResult
   ├─ MetricCards
   ├─ ChartPanel
   ├─ DataTable
   └─ SummaryCard
```

首期由 `AnalysisWorkspaceView` 从路由解析 datasetId/sessionId 并管理本地工作区状态，不使用 `analysisStore`。DatasetPanel 只发出 dataset-change 和 question-select；MessageInput 发出 send；ToolCallCard 发出 inspect/retry；Result 不改变 Tool Result。首期没有取消操作；离开页面不会停止服务端分析，完成的消息和证据会保存到会话中供再次查看。

关键不变量：发送时锁定当前 dataset_id；切换数据集需新建或确认切换会话；Tool 失败不构造总结；ChartPanel 的数据源只能是 `result.chart`。
