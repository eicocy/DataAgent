# 前端交互状态规范

| 类型 | 状态 | 规则 |
|---|---|---|
| 页面查询 | initial/loading/ready/empty/error | 首次加载保留稳定区域，错误可重试 |
| 后台刷新 | refreshing/stale | 保留旧内容并标注更新中 |
| 表单 | idle/invalid/submitting/success/error | noValidate、首错焦点、防重复 |
| 上传 | selected/validating/uploading/parsing/ready/failed | 文件级错误不清空其他有效项 |
| Agent | idle/submitting/succeeded/partial/failed | 同步请求期间锁定输入并显示等待状态；失败保留问题；首期无实时进度与服务端取消 |
| Tool | validating/running/succeeded/failed | 结构化错误、可重试性 |

Toast 用于确认；需修复的错误留在字段、Dialog 或面板中。加载按钮尺寸固定；旧请求不能清除新请求 busy 状态。

所有状态组件以 WCAG 2.2 AA 为基线：状态不能只靠颜色表达，键盘焦点可见，动态结果通过合适的 live region 宣布。
