# 路由与页面设计

| Name | Path | View | Auth | 主要参数 |
|---|---|---|---|---|
| Login | `/login` | LoginView | public | redirect |
| Register | `/register` | RegisterView | public | — |
| Dashboard | `/` | DashboardView | required | — |
| Datasets | `/datasets` | DatasetListView | required | q/type/page/size |
| DatasetUpload | `/datasets/upload` | DatasetUploadView | required | — |
| DatasetDetail | `/datasets/:datasetId` | DatasetDetailView | required | tab |
| Analysis | `/analysis/:sessionId?` | AnalysisView | required | datasetId |
| Sessions | `/sessions` | SessionListView | required | q/page/size |
| History | `/history` | HistoryListView | required | q/status/tool/page/size |
| HistoryDetail | `/history/:recordId` | HistoryDetailView | required | — |
| Profile | `/profile` | ProfileView | required | — |
| Forbidden | `/403` | ForbiddenView | required | — |

守卫顺序：恢复登录态 → 检查认证 → 校验路由参数格式 → 加载必要资源。401 保存非敏感目的路由并转登录；403 转专用页面；404 区分资源不存在。页面标题为 `{页面} — DataLens Agent`。
