# 核心组件拆分

| 组件 | 输入 | 输出 | 职责 |
|---|---|---|---|
| AppLayout | currentRoute/user | navigate/logout | 侧栏、顶栏、主内容 |
| DataTable | columns/rows/page/loading | sort/page/action | 语义表格和状态 |
| SearchField | modelValue/loading | update/submit/clear | IME 安全搜索 |
| AppDialog | open/title/intent | close/confirm | 焦点、Escape、恢复 |
| ToastViewport | queue | dismiss/action | 全局反馈 live region |
| EmptyState | kind/title/action | primary | 空/无结果/失败 |
| DatasetUploader | rules/jobs | select/remove/retry | 上传队列与状态 |
| ToolCallCard | ToolCall | inspect/retry | 结构化执行证据 |
| EvidenceRail | ExecutionStep[] | select | 产品级执行阶段 |
| ChartPanel | ChartSpec | viewChange | ECharts 与表格替代 |

共享组件拥有可访问语义、状态和 Token；页面只提供业务文案和数据。
