# 前端数据模型设计

核心类型：

- `User { id, username, created_at }`
- `Dataset { id, name, file_type, row_count, column_count, file_size, status, uploaded_at }`
- `DatasetColumn { id, name, display_name, data_type, missing_count, unique_count, sample_values }`
- `AnalysisSession { id, dataset_id, title, message_count, updated_at }`
- `AnalysisMessage { id, session_id, role, content, record_id?, created_at }`
- `ToolCall { tool_call_id, tool_name, parameters, status, duration_ms, result_summary?, error? }`
- `AnalysisRecord { id, question, tool_calls, tool_result, answer?, chart?, execution_time, status }`
- `ChartSpec` 见图表设计。

时间在 DTO 中保持 ISO 8601 字符串，显示层按 Asia/Shanghai 格式化。金额用字符串或 Decimal 对应表示，避免 JS 浮点作为权威计算。
