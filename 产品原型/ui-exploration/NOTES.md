# 五种分析视图探索原型

**问题：** DataLens Agent 的同一次分析，应该用哪种信息层级让用户最容易理解结论与计算依据？

打开 [交互原型](../ui-exploration-five.html)，使用底部切换栏或键盘左右方向键切换 A–E。也可以在地址后加 `?variant=A` 至 `?variant=E`，直接打开某一方案。

| 方案 | 第一眼看到什么 | 主要优势 | 需要权衡 |
|---|---|---|---|
| A 引导式分析 | 当前步骤、问题和图表 | 初学者知道下一步做什么 | 多步流程占用首屏空间 |
| B 对话式分析 | 问题和回答 | 连续追问自然，学习成本低 | 计算证据要靠消息内嵌呈现 |
| C 数据驾驶舱 | 指标卡和地区对比 | 经营概览最直接 | Agent 的调用过程不够突出 |
| D 分析笔记本 | 问题、方法、数据、结论 | 可复核性最强，适合展示分析过程 | 首屏内容较密，偏专业 |
| E 决策报告 | 一句话结论和核心数字 | 适合汇报与分享 | 继续提问的入口不明显 |

五种页面都使用 `sample-data/sales_demo.csv` 的同一组示例值：10 条订单、总销售额 37,093 元；华南 12,439、华东 10,777、西南 9,979、华北 3,898 元。该原型仅用于比较视觉和信息结构，没有登录、上传、模型调用或持久化能力。

**用户选择：** 待确定。确定方案后，把选中的结构重做进正式 Vue 页面，并移除其余探索稿。
