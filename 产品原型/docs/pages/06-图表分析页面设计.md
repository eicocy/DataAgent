# 图表分析页面设计

图表页用于放大查看一个 ChartSpec，并提供同源数据表。图表标题、维度、指标、单位、图例和来源 Tool 必须可见；无有效数据时显示空状态，不渲染零高度或误导性图形。

配置面板只能从 Tool Result 已有字段中选择维度和指标；`bar`、`line`、`pie` 是首期白名单。前端把 ChartSpec 转为 ECharts option，永不执行模型生成脚本。

组件：ChartCanvas、ChartToolbar、ChartDataTable、ChartConfigPanel、ChartSourceBadge。接口数据来自分析记录，不单独重新计算。
