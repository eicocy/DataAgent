# 用户系统页面设计

## 页面范围

登录、注册和个人信息。公开页使用独立品牌布局；登录后个人信息复用应用壳。

## 核心行为

- 登录成功进入 Dashboard；失败使用表单顶部错误，保留用户名、清空密码。
- 注册先展示密码要求，重复用户名映射到用户名字段。
- 密码默认遮罩，显示/隐藏按钮可键盘操作，允许粘贴和密码管理器。
- 个人信息只展示当前账号和数据边界；真实权限以服务端为准。

## 状态与接口

| 页面 | API | 状态 |
|---|---|---|
| 登录 | `POST /api/v1/auth/login` | idle/submitting/invalid/network-error/success |
| 注册 | `POST /api/v1/auth/register` | idle/validating/duplicate/error/success |
| 个人信息 | `GET /api/v1/auth/me` | loading/ready/401/error |

## 组件

AuthLayout、LoginForm、RegisterForm、PasswordField、UserProfileCard、FormAlert。验收重点是标签关联、泛化登录错误、重复提交阻止和重新登录返回原任务。
