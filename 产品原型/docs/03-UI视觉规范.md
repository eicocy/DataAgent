# UI 视觉规范

视觉规范以根目录 `DESIGN.md` 为准。本文件记录原型实现映射：

- 颜色和尺寸：`assets/css/tokens.css`。
- 全局文字、焦点和滚动条：`base.css`。
- 按钮、表格、表单、状态、Dialog、Evidence Rail：`components.css`。
- 页面布局和响应式：`pages.css`。

## 识别元素

Evidence Rail 使用青绿色垂直轨道串联分析阶段；青绿只表达已由程序工具验证的证据，不用于普通装饰或主按钮。

## 图表序列

`#2F6BFF`、`#18A999`、`#7867D8`、`#F08A4B`、`#8795A8`。所有图表同时提供文本标题、单位、图例和数据表。
