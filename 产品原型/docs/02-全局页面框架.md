# 全局页面框架

登录后采用侧栏 + 顶栏 + 内容区。侧栏承担稳定的一级导航；顶栏显示页面名称、原型标识和用户入口；内容区根据任务切换为概览、列表、详情或工作台。

```text
┌──────────────┬─────────────────────────────────────────┐
│ 品牌/一级导航 │ 顶栏：页面标题      原型标识  用户        │
│              ├─────────────────────────────────────────┤
│ Dashboard    │ 页面标题 + 说明 + 主操作                 │
│ 数据集       │                                         │
│ 智能分析     │ 页面主内容                               │
│ 会话         │                                         │
│ 历史         │                                         │
└──────────────┴─────────────────────────────────────────┘
```

页面跳转后主标题成为焦点目标。窄屏时原型隐藏侧栏，正式 Vue 工程应转换为可聚焦、可关闭并恢复焦点的抽屉。
