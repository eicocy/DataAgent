# 产品信息架构

```text
公开区
├─ 登录
└─ 注册

登录区
├─ Dashboard
├─ 数据集
│  ├─ 数据集列表
│  ├─ 上传数据
│  └─ 数据集详情
│     ├─ 数据预览
│     └─ 字段信息
├─ 智能分析
│  ├─ 分析工作台
│  ├─ Agent 执行过程
│  ├─ Tool 调用详情
│  └─ 分析结果
├─ 图表分析
├─ 分析会话
├─ 分析历史
│  └─ 分析详情
└─ 个人信息
```

一级导航固定为 Dashboard、数据集、智能分析、分析会话、分析历史。数据预览、字段、Tool 详情和分析详情属于上下文页面，不占用一级导航。
