# 页面状态规范

| 状态 | 表现 | 用户下一步 |
|---|---|---|
| 初始加载 | 保留页面骨架，在内容区显示 spinner | 等待或返回 |
| 后台刷新 | 保留已有内容，显示轻量更新状态 | 可继续阅读 |
| 空数据 | 说明这里应有什么 | 上传数据/开始分析 |
| 无搜索结果 | 显示查询条件与清除入口 | 清除筛选 |
| 成功 | 内容更新 + 简短 Toast | 继续当前任务 |
| 可恢复失败 | 原因、影响范围、重试 | 重试/修改输入 |
| 无权限 | 说明所需权限，不暗示没有数据 | 返回允许页面 |
| Agent 失败 | 保留问题和已完成步骤 | 重试/修改问题 |
| 总结失败 | 展示真实 Tool Result，隐藏结论 | 重新生成总结 |

状态切换不得改变主要按钮位置或伪造尚未完成的数据。
