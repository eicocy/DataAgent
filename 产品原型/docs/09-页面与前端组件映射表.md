# 页面与前端组件映射表

| 页面 | View | 核心组件 | Store |
|---|---|---|---|
| 登录/注册 | LoginView/RegisterView | AuthLayout、PasswordField、FormAlert | authStore |
| Dashboard | DashboardView | MetricCard、RecentDatasetTable | datasetStore |
| 数据集列表 | DatasetListView | SearchField、DataTable、Paginator | datasetStore |
| 上传 | DatasetUploadView | DatasetUploader、UploadQueueItem | datasetStore |
| 数据集详情 | DatasetDetailView | DatasetSummary、PreviewTable、ColumnTable | datasetStore |
| 分析工作台 | AnalysisView | DatasetPanel、ChatPanel、EvidenceRail、ToolCallCard、AnalysisResult | analysisStore |
| 图表 | ChartView | ChartPanel、ChartDataTable、ChartSourceBadge | analysisStore |
| 会话 | SessionListView | SessionTable、AppDialog | analysisStore |
| 历史 | HistoryListView/DetailView | HistoryTable、RecordDetail | analysisStore |

AppLayout、Button、AppDialog、ToastViewport、EmptyState 和 DataTable 为共享组件，不在页面内重复实现。
