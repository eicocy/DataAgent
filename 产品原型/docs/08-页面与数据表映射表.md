# 页面与数据表映射表

| 页面 | 主要表 | 说明 |
|---|---|---|
| 登录/个人信息 | users | 密码哈希永不返回前端 |
| 数据集列表/详情 | datasets | 必须按 user_id 查询 |
| 字段信息 | dataset_columns | 通过 dataset 所有权授权 |
| 分析工作台 | analysis_sessions、analysis_messages、analysis_records | 数据集来自 datasets |
| 会话列表 | analysis_sessions | message_count 可聚合或维护 |
| 历史列表/详情 | analysis_records | 关联 dataset/session/messages |
| 图表结果 | analysis_records.chart_json | 来源 ToolCall 可追溯 |
