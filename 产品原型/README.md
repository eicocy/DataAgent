# HTML 产品原型

从 [index.html](index.html) 进入原有多页原型。它使用原生 HTML、CSS 和少量 JavaScript，无需服务端、依赖或网络资源；页面数据为模拟数据，不执行真实登录、上传、计算或保存。

另有 [五种分析视图探索原型](ui-exploration-five.html)，用同一份销售样例比较引导式、对话式、数据驾驶舱、分析笔记本和决策报告布局。底部切换栏或键盘左右方向键可切换方案；具体差异见 [方案说明](ui-exploration/NOTES.md)。

新增 [开源项目启发的五种分析工作台 UI](ui-open-source-five.html)，对比清晰对话、Agent 执行舱、可信指标台、数据工坊和分析审阅台。页面顶部切换方案，`?variant=A` 至 `?variant=E` 可直达；[方案说明与参考来源](ui-open-source/NOTES.md)记录各自的借鉴点、视觉选择和取舍。此页同样只使用静态销售样例，可直接通过 `file://` 打开。

## 查看重点

- Dashboard 的信息层级与快速入口。
- 数据集上传、解析、预览和字段质量状态。
- 分析工作台的三栏布局与 Evidence Rail。
- Tool 名称、结构化参数、结果摘要和耗时。
- 图表、表格与 AI 总结之间的关系。
- 空、加载、成功、失败和无权限状态。
